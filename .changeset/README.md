# Changesets

Pending release notes for this package live here as temporary `.md` files.

- Add a changeset: `npm run changeset`
- Check status: `npm run changeset:status`
- Version from changesets: `npm run version-packages` (maintainers / release CI)

Do not link durable MDCP shards or ADRs to pending `.changeset/*.md` files — those notes are folded into `CHANGELOG.md` at release.
