# Maps+ preset

Shipped [gesture style](./gesture-style.md) (AppleKit). Two-finger [pan](./pan.md), pinch [zoom](./zoom.md), two-finger rotate for camera [rotate](./yaw.md) / ghost, Option (`⌥`)+two-finger for [orbit](./orbit.md). Chosen to reduce conflict with OS three-finger system gestures.

Not a [feel preset](./feel-preset.md): changing Slow / Default / Fast does not change this style. v1 ships Maps+ only — see [CAD](./cad-preset.md) for the future three-finger orbit style.
