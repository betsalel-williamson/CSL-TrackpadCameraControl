# Hot configuration

Changing a value in Options → Trackpad Camera Control or the in-game Debug panel takes effect immediately (next gesture or sooner) without restarting the game, mod, or Capture backend. Both surfaces share one live feel blob; one dirty bit; coalesced autosave so values survive quit.

Ship product knobs are feel / Sensitivity only — not style-table remapping and not orbit pitch (that is an [apply constant](./apply-constant.md)).
