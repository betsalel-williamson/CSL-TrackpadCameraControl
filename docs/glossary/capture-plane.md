# Capture plane

First tick plane **inside the CSL mod**: the platform backend turns OS trackpad input into one shared **primitive / frame** contract (honest finger count, centroid delta, pinch, rotate, modifiers). Capture does **not** decide pan, orbit, zoom, or yaw — those belong to Policy resolve and Apply.

Ship Capture is AppKit, implemented in the [gesture library](./gesture-library.md) and wired by the [mod surface](./mod-surface.md). Backends must emit finger counts they can actually express so style rows never claim chords Capture cannot fill.
