# Feel preset

A saved or built-in **feel profile**: per-op enables, reverse flags, [Sensitivity](./sensitivity.md) values, and orbit pitch min/max (and other product-surface feel fields).

Built-in profiles: **Slow**, **Default**, and **Fast**. Named **Save as… / Load** stores user profiles on the settings persist envelope. **Reset to factory** restores the Default profile.

A feel preset is **not** a [gesture style](./gesture-style.md) (Maps+ vs CAD orbit trigger).
