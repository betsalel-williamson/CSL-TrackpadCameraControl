# Vanilla camera suppress

While Trackpad Camera Control is enabled (and Cities Harmony is present), the mod gates vanilla **precise trackpad** scroll-zoom so it does not fight trackpad camera ops. Middle-mouse orbit and mouse wheel remain vanilla.

**Scroll:** precise trackpad two-finger scroll is suppressed for vanilla zoom so it can [pan](./pan.md); a real mouse wheel is allowed to vanilla-zoom. When Options/menus are open or the cursor is over an active popup, mod camera ops do not run and UI scroll is free.

Edge pan, keyboard camera keys, and gamepad stay. Disable the mod to restore full vanilla camera input.
