# Gesture style

How trackpad gestures map to camera ops — especially how [orbit](./orbit.md) is triggered. v1 ships only [Maps+](./maps-plus-preset.md) (AppleKit): two-finger pan, pinch zoom, two-finger rotate, Option (`⌥`)+two-finger orbit.

[CAD](./cad-preset.md) (three-finger orbit) is a **future** style — not a player choice in this release.

Gesture style is **not** a [feel preset](./feel-preset.md) (Sensitivity / Slow–Fast / Save as…). Feel presets sit on top of the shipped Maps+ bindings; they never rewrite which fingers map to Zoom / Pan / Rotate / Orbit.
