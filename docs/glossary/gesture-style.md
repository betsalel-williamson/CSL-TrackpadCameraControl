# Gesture style

How trackpad chords map to camera ops — especially how [orbit](./orbit.md) is triggered. Ship play uses the Maps+ **seed** in the [style binding table](./style-binding-table.md): two-finger [pan](./pan.md), pinch [zoom](./zoom.md), two-finger rotate, Option (`⌥`)+two-finger orbit.

CAD (three-finger orbit) is a **future** style behind a compile gate — omitted from the ship DLL and not a player choice. Gesture style is orthogonal to a [feel preset](./feel-preset.md).
