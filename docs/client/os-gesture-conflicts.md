# OS gesture conflicts

Multi-finger gestures are often reserved by the operating system (mission control, virtual desktops, window drag, scroll). This mod cannot override every OS policy; Options presets and toggles help you choose a conflict-light setup.

In-game, vanilla scroll-zoom is a separate conflict: while the mod is enabled, [vanilla camera suppress](../glossary/vanilla-camera-suppress.md) turns that path off (Cities Harmony required). OS-level reservations still apply.

## General guidance

- Prefer **Maps+** if three-finger system gestures matter to you — orbit uses modifier+two-finger instead.
- Prefer **CAD** if you want three-finger orbit and are willing to remap or disable conflicting OS gestures.
- If two-finger pan still vanilla-zooms, confirm Cities Harmony is subscribed and the mod is enabled — then disable the mod to restore vanilla scroll-zoom.
