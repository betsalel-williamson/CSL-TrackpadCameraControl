# Personas

Who this product is for on the rewrite ship surface.

## Primary — Trackpad city-builder

Cities: Skylines I player on a **laptop trackpad** (often macOS) who wants Maps+ camera control without a three-button mouse.

**Needs:** clear install path, Maps+ chords that match muscle memory, Sensitivity and Slow / Default / Fast that feel hot.

**Guide home:** [install and first run](./install-and-first-run.md), [feel presets](./feel-presets.md), [options and hot tuning](./options-and-hot-tuning.md).

## Beta tester — early adopter

Willing to install from a **GitHub Release** or local rewrite build before Workshop is the main path. Comfortable with Content Manager, Cities Harmony, and reporting capture bugs.

**Guide home:** [Install and first run](./install-and-first-run.md). Build / copy steps: `rewrite/docs/developer/local-mvp-install.md`.

## Future — CAD-style camera user

Prefers **three-finger orbit**. Not a ship audience while `EnableCadGestureStyle` is off — Maps+ Option (`⌥`)+two-finger orbit remains the only player path.

## Out of scope for this guide

Contributors implementing Capture / Policy / Apply or packaging — use the developer guide. Maintainers announcing releases — use the shipping community docs until cutover.
