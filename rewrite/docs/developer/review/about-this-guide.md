# Rewrite v1 audit (review guide)

**Audience:** Contributors and agents reconciling the built `rewrite/` mod with greenfield lessons (L1–L12) and v1 product scope.

**Purpose:** Document organized product feedback, the phased audit/cleanup plan, and specialist findings (strengths, weaknesses, critical improvements) as small MDCP shards — not a monolith report.

**Workflow:**

1. Read [organized product feedback](./v1-product-feedback.md) (user scope vs prototype carryover).
2. Follow [v1 audit and cleanup plan](./v1-audit-plan.md) — atomic commit groups, hooks on every push.
3. Read area shards after specialist passes (capture, settings, policy, UI, release, tests).
