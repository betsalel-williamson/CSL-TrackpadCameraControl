# UI parity

**UI parity** (also written **1:1** for Options and Debug) means the player-facing **look, labels, control kinds, section order, and interactions** match the shipping Maps+ feel surface.

It does **not** mean the rewrite sources match shipping C#. Internals follow the three planes, a [style binding table](./style-binding-table.md), and one feel catalog with two hosts.

Gesture **dynamics** parity is separate: Maps+ chords and camera/selection outcomes, not UI widgets. Both are defined under _Parity with shipping_ in the features guide.
